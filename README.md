# KG ACADEMY – Foundation V0.1

The Complete Beverage & Hospitality Learning Platform.

## Current foundation
- React + TypeScript + Vite
- Arabic/English interface switch
- RTL/LTR layout support
- Initial landing page and academy overview
- Responsive starter styling

## Run locally
1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Important
This is a frontend foundation only. Authentication, database, real courses, recipe persistence,
admin permissions, certificates, and production deployment are not implemented yet.
Do not add secrets to frontend code. Configure Supabase only in a later secured phase.
